Planetary System

Cyclo-V is a long-running visualization project I started in 2019. It began as hand-drawn maps, then slowly turned into a full 3D project once I started pushing for something that could beautiful and realistic. This page effectively reperesents the project’s timeline form early 2D concept work in Krita to its finalization in Blender, and the changes that shaped the final look you’re seeing now.

What is Cyclo-V?

In this visualization, Cyclo-V is a fictional planet positioned within a larger fictional setting. The goal in this project wasn't to “explain the lore,” it’s to build a grounded, believable planet: atmosphere, cloud layers, surface, and moons. The renders you’re seeing focus on exclusivly the planets esthetics and sapshots of the journey to ceate the final renderrs this page is a window what went behind it.

2D Map Design

Before anything in 3D, I spent years drawing 2D maps. Each map was am attempt to add more detail and more variables than the last, but I never fully committed to making a hyper-detailed “final” map. Instead, iterating and leaving room for creativity in each attempt. Moving into Blender, gave me the ability to much more easily make a realistic attempt.

Texture Mapping

I used those 2D maps as the planet’s surface textures, but the limitations of an image texture is that it relies on pixels to display details, meaning as soon as camera was zommed onto the urface, the pixelation limitations became obvious. To solve that, I requuires understanding how textures are displayed onto 3D objects.

In Blender, textures are projected onto a model using UVs and vector mapping, which control how the texture is wrapped and oriented on the surface, respectively. So while adding detail over the textures wouldn't fix the pixelation, recreating vector logic and subtly mixing in noise prior to applying the 2D maps will keep the overall map design while adding much more surface detail and variation.

First attempt

Afterwards I made the first version of the planet in Blender, for a while it satisfied me in how it looked but eventually I realized it was too low quality, and there were some parts, Mainly in the clouds and atmosphere, that didnt look realisyic or appealing.I wanted to make something that looked more like a real planet, and less like a 3d model.
